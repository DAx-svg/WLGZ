三、你到公司后第一步（最紧急）
================================================================================

3.1 断开网络（最保险）
----------------------------------------
到了公司先把那台电脑的网线拔了或关 WiFi，确保不会自动连上云端同步。

3.2 立即备份数据库
----------------------------------------
打开命令行（cmd），进入项目目录，执行：

    copy material.db material.db.SAFE_20260611

确认备份文件里有完整数据（物料数量应该远大于5，出库/售后记录不为0）：

    python -c "import sqlite3; db=sqlite3.connect('material.db.SAFE_20260611'); db.row_factory=sqlite3.Row; print('物料:', db.execute('SELECT COUNT(*) FROM materials').fetchone()[0], '条'); print('出库:', db.execute('SELECT COUNT(*) FROM outbound_records').fetchone()[0], '条'); print('售后:', db.execute('SELECT COUNT(*) FROM after_sales_records').fetchone()[0], '条'); print('故障:', db.execute('SELECT COUNT(*) FROM fault_records').fetchone()[0], '条'); print('版本变更:', db.execute('SELECT COUNT(*) FROM version_changes').fetchone()[0], '条')"

如果物料数量 > 5，且出库/售后记录不为 0，说明数据完好，继续下一步。

3.3 删除同步状态文件（最关键的一步！）
----------------------------------------
执行：

    del sync_state.json

这个文件记录了「上次同步时云端有哪些 SN」。如果不删，同步脚本会认为你本地独有的数据
是「在云端被用户删掉的」，然后帮你全部删掉——跟主电脑发生的一模一样。

删掉后，本地独有的数据会被正确识别为「本地新增」，推送到云端。


四、恢复云端入口
================================================================================

你那台电脑的浏览器登录 https://www.pythonanywhere.com（账号跟主电脑是同一个）。

4.1 打开 Bash Console
----------------------------------------
顶部点 Consoles → 点已有的 Bash console，或新建一个。

4.2 改回 token
----------------------------------------
在 Bash Console 里执行这两行：

    cd ~/WLGZ
    sed -i "s/wlgz-sync-2026-BLOCKED/wlgz-sync-2026/" app.py

验证改成功了：

    grep "wlgz-sync" app.py

应该看到 wlgz-sync-2026（不带 BLOCKED）。

4.3 Reload
----------------------------------------
顶部点 Web 标签 → 点绿色 Reload 按钮。
