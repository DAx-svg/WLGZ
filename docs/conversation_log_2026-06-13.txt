  一、云端 504 故障排查
================================================================================

现象：
  用户访问 https://daxsvg.pythonanywhere.com 报 504 Load Balancer 错误

排查过程：
  1. HARAKIRI 日志分析 — uWSGI worker 在处理 POST /api/material/add 时卡死
     被反复 kill/respawn，最终崩溃
  2. 发现远程有 11 个新提交（用户另一台电脑推送的功能）
  3. Source code 路径被错误设置为 /home/DAxsvg/mysite，
     实际应用在 /home/DAxsvg/WLGZ — 已修复
  4. material.db-journal 残留（DELETE 模式崩溃遗留）— 已删除
  5. uWSGI socket 损坏导致 reload 持续失败
  6. PythonAnywhere 控制台服务不稳定，多次崩溃

================================================================================
  二、远程代码审查与 Bug 修复
================================================================================

本地 HEAD：1204e16 → 拉取远程 11 个提交后 → 81ee8e4

Bug 1（致命）：api_category_trend SQL 拼接错误
  文件：app.py line 2067/2070
  问题：cat_clause = 'AND m.category_id = ?'  缺少前导空格
        拼接为 WHERE 1=1AND ... → 非法 SQL token "1AND"
  修复：改为 ' AND m.category_id = ?'（加空格）

Bug 2（高）：BOM 字符
  文件：app.py line 1
  问题：远程文件以 EF BB BF (UTF-8 BOM) 开头
        Python 3.10 可能因 BOM 导致 WSGI 导入异常
  修复：移除 BOM 字节

Bug 3（高）：数据库写锁阻塞
  文件：app.py get_db() line 43
  问题：PRAGMA journal_mode=DELETE + Python 3.10 默认 isolation_level='DEFERRED'
        导致写操作互相阻塞，worker 卡死
  修复：
    - 切换到 PRAGMA journal_mode=WAL（单 worker 环境安全）
    - init_db() 启动时自动清理残留 -journal/-wal/-shm 文件

Bug 4（低）：init_db 启动无自动恢复
  文件：app.py init_db()
  修复：在 init_db 开头添加 glob 扫描，自动删除 DATABASE 旁的所有锁文件

寄修逻辑审查：
  云端在 api_outbound 新增了"故障出库寄修"入口，与本地 api_fault 的寄修入口并存
  两处都有状态守卫（寄修中禁止出库/入库），不存在运行时冲突
  功能冗余但安全

================================================================================
  三、数据库锁问题处理
================================================================================

问题链：
  1. DELETE journal_mode 在 NFS 上文件锁不稳定
  2. HARAKIRI 杀死 worker 时未清理 journal 文件
  3. 新连接尝试 hot journal rollback 失败 → database is locked
  4. 所有写入操作阻塞，busy_timeout=5000 后超时
  5. 用户删除 material.db 后文件更碎片化

尝试的修复：
  - rm material.db-journal → 控制台卡死
  - sqlite3 .dump → 控制台卡死
  - cp material.db.bak2 material.db → 控制台崩
  - Files 页面重命名 → 界面不支持

最终方案：
  在 init_db() 添加启动时自动清理 + 强制 WAL 模式
  推送到 GitHub，Web Reload 时自动执行
